CardVault

Offline encrypted secrets vault for the M5Stack Cardputer ADV — v__VERSION__

  1. Use Chrome or Edge on a desktop computer.
  2. Turn the Cardputer off, hold G0, plug in USB-C, then release.
  3. Click Install and choose the USB serial port.
Before you install: flashing replaces whatever firmware is on the device. If you already use CardVault, make an SD backup first — erasing the flash erases the vault. Verify the image checksum against the GitHub release.
